# ML Project — VAT Algorithm

Machine learning project implementing and analysing the VAT (Visual Assessment of cluster Tendency) algorithm for evaluating dataset clusterability before applying clustering methods.

## Contents

- `VAT - Final Project.ipynb` — Full implementation and analysis notebook
- `VAT_Algorithm_Report.pdf` — Detailed report on the algorithm and findings

## About VAT

VAT (Visual Assessment of cluster Tendency) is a technique used to visually assess whether a dataset has meaningful cluster structure before running clustering algorithms. It helps avoid applying clustering to datasets that have no natural groupings.

Python · Jupyter Notebook · Scikit-learn
